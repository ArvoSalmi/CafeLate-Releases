# CafeLate · Descargas oficiales

Reproductor gratuito de música local para Windows y Android.

Este repositorio público contendrá los instaladores y las notas de las versiones de CafeLate. El código fuente y su historial de desarrollo se mantienen en un repositorio privado separado.

Todavía no hay una versión estable publicada. Cuando esté disponible, los paquetes oficiales aparecerán en [Releases](https://github.com/ArvoSalmi/CafeLate-Releases/releases).

CafeLate reproduce música guardada en el dispositivo, sin cuentas ni registro. Favoritos, listas y preferencias permanecen en el dispositivo. La conexión a internet solo se necesita para consultar o descargar actualizaciones y para abrir enlaces externos.

Apoyo voluntario: [Invitar un Cafecito](https://cafecito.app/matedetroll).
