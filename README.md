# CafeLate · Descargas oficiales

Reproductor gratuito de música local para Windows y Android. Sin cuentas ni registro; favoritos, listas y preferencias permanecen en tu dispositivo. El código fuente y su historial se mantienen en un repositorio privado separado. Aquí solo se publican paquetes y documentación.

[Descargar la última versión](https://github.com/ArvoSalmi/CafeLate-Releases/releases/latest) · [Todas las versiones](https://github.com/ArvoSalmi/CafeLate-Releases/releases)

## Instalación

- **Windows x64:** extraer todo el ZIP en una carpeta con permisos de escritura y ejecutar `cafelate.exe`. Conservar las carpetas y DLL del paquete junto al ejecutable.
- **Android 7 o posterior:** instalar el APK y aceptar la confirmación del sistema. Puede ser necesario permitir la instalación desde CafeLate al actualizar.

## Actualizaciones desde la app

Desde 0.2.0, Ajustes → Buscar actualizaciones descarga y verifica el paquete correspondiente. Windows cierra y reinicia la app para aplicarlo; Android abre el instalador del sistema, que requiere tu confirmación. No se necesita una cuenta de GitHub. La firma Ed25519 del manifiesto y el SHA-256 verifican procedencia e integridad. No se ejecuta código descargado de una rama.

Para probar una actualización, instalar 0.2.0 y luego buscar 0.2.1 desde la app. La versión recomendada para usar directamente es la última publicada.

La antigua 0.1.0 requiere instalar manualmente una versión nueva una vez: su botón solo abría la página de descargas. El APK de depuración 0.1.0 tenía una firma diferente; antes de reinstalar, conservar los datos importantes. Desinstalar elimina los datos y las copias privadas de la app. Los APK desde 0.2.0 usan el mismo certificado permanente.

## Funciones

Biblioteca local, favoritos y listas; importación de carpetas con subcarpetas; reproducción aleatoria; selección múltiple y menús contextuales; cinco ambientes animados y seis paletas combinables. La compatibilidad de audio depende del motor y del archivo real.

Búsqueda pública de YouTube y descarga de audio original con miniatura para contenido propio o autorizado. No convierte a MP3 ni elude restricciones; YouTube puede modificar o limitar su disponibilidad. Escuchar archivos locales no necesita internet. La búsqueda, las descargas, las actualizaciones y los enlaces externos sí utilizan conexión.

Esta aplicación está en una etapa temprana. Las notas de cada versión indican la validación realizada y las limitaciones pendientes de probar en equipos reales.
